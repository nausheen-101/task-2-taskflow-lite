# 🌿 TaskFlow Lite

TaskFlow Lite is a simple and responsive task management web application built using **HTML, CSS, and Vanilla JavaScript**. It allows users to manage their daily tasks efficiently with a clean black-and-green themed user interface and animated background.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📂 Filter tasks (All, Active, Completed)
- 💾 Save tasks using Local Storage
- ✔ Input validation
- 📊 Task counter
- 🌿 Empty state message
- ✨ Animated canvas background
- 📱 Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Local Storage API
- Canvas API (Animated Background)

## ▶️ How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension (if not already installed).
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. Start managing your tasks.
